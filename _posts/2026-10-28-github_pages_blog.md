## 블로그를 만들며

보안 공부와 활동 내용을 기록하기 위해 GitHub Pages로 블로그를 만들었다.
처음에는 Chirpy 테마로 시작했고, 이후 원하는 디자인에 맞게 수정했다.

## 구성

첫 화면에는 인사말과 폴더 캐릭터를 배치했다.
Enter를 누르면 홈 화면으로 이동하고, 카테고리별로 글을 찾아볼 수 있도록 구성했다.

- Home: 카테고리와 최근 글
- Posts: 전체 글 목록
- About: 블로그 소개와 활동 이력

## 글을 올리는 방법

`_posts` 폴더에 Markdown 파일을 만들고,
제목과 날짜, 카테고리를 설정한 뒤 본문을 작성한다.

변경 내용을 커밋하면 GitHub Actions를 통해 자동으로 배포된다.

## 기억할 점

수정한 내용이 바로 보이지 않을 때는 먼저 배포가 완료됐는지 확인한다.
배포가 성공했는데도 이전 화면이 보인다면 시크릿 창에서 확인해볼 수 있다.

## 앞으로

공부한 내용과 문제 풀이를 조금씩 정리하면서 블로그를 채워나갈 예정이다.
